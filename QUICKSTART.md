## Quick Customization (2-5 minutes)

### Change Your Name
Find this line:
```html
<h1 class="hero-title">
    ⭐ MOE KYAW AUNG ⭐<br/>
    <span>SENIOR ANDROID DEVELOPER</span>
</h1>
```

Replace with:
```html
<h1 class="hero-title">
    ⭐ YOUR NAME ⭐<br/>
    <span>YOUR TITLE</span>
</h1>
```

### Change Colors (1 minute)
Find this section:
```css
:root {
    --color-accent-primary: #3b82f6;    /* Blue */
    --color-accent-secondary: #10b981;  /* Green */
}
```

Try:
```css
:root {
    --color-accent-primary: #8b5cf6;    /* Purple */
    --color-accent-secondary: #ec4899;  /* Pink */
}
```

### Add Your Projects (2 minutes)
Find portfolio section and duplicate this:
```html
<div class="app-card fade-up">
    <div class="app-icon">📱</div>
    <div class="app-name">Your Project</div>
    <div class="app-desc">Description</div>
    <a href="https://github.com/yourlink" class="app-link">View Code</a>
</div>
```

### Update Social Links (1 minute)
Find this:
```html
<div class="social-card fade-up" onclick="window.open('YOUR_URL', '_blank')">
    <div class="social-icon"><i class="fab fa-github"></i></div>
    <div class="social-name">GitHub</div>
    <div class="social-handle">@yourhandle</div>
</div>
```

Replace `YOUR_URL` with your actual URL.

## Troubleshooting (2 minutes)

### Page doesn't look right?
→ Hard refresh: `Ctrl+Shift+R` (Windows) or `Cmd+Shift+R` (Mac)

### Styles not applied?
→ Close browser completely and reopen

### Links not working?
→ Check URL is correct, test in new tab

### Mobile looks weird?
→ Refresh page, zoom to 100%

### Changes not showing?
→ Save file, then refresh browser
