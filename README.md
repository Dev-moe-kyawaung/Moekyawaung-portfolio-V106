## 🎨 Customization Guide

### Change Colors

Edit the CSS custom properties in the `<style>` section:

```css
:root {
    /* Change primary accent color */
    --color-accent-primary: #3b82f6;
    
    /* Change background color */
    --color-bg-primary: #0a0a0a;
    
    /* Change text color */
    --color-text-primary: #e0e0e0;
}
```

### Add Your Content

#### Hero Section
```html
<h1 class="hero-title">
    ⭐ YOUR NAME ⭐<br/>
    <span>YOUR TITLE</span>
</h1>
```

#### Skills
```html
<span class="skill-chip">Your Skill</span>
```

#### Projects
```html
<div class="app-card">
    <div class="app-icon">📱</div>
    <div class="app-name">Project Name</div>
    <div class="app-desc">Description</div>
    <a href="link" class="app-link">View Code</a>
</div>
```

#### Social Links
```html
<div class="social-card" onclick="window.open('your-link', '_blank')">
    <div class="social-icon">Your Icon</div>
    <div class="social-name">Platform</div>
    <div class="social-handle">Handle</div>
</div>
```

## 🐛 Troubleshooting

### Form not submitting?
- Check browser console for errors
- Ensure JavaScript is enabled
- Verify email format

### Mobile menu not working?
- Clear browser cache
- Check JavaScript console
- Enable JavaScript

### Styles not loading?
- Hard refresh browser (Ctrl+Shift+R)
- Check CSS custom properties support
- Verify no CSS conflicts

### Animations not smooth?
- Check GPU acceleration
- Reduce number of simultaneous animations
- Update to latest browser
